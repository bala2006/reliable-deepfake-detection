System design

One supervised pass.
Two complementary outputs.

RL-ROI-Net v2 samples a fixed number of frames uniformly, runs aligned face crops through an EfficientNet-B4 path, and reports both a real/fake classification and fixed-ROI forgery-localization evidence.

i

Implementation status. The system has measured FF++ experiments and supports local video review. External-dataset generalization remains unmeasured, so the displayed evidence must not be treated as a definitive authenticity verdict.

Model outputs

Two heads, one supervised feature extractor.

Every uniformly sampled face crop follows the same path; there is no learned selection or stopping decision.

M1

Two backbone paths

The deployed path uses frozen `honi05`; the alternate `train.py` path without `--verdict` uses ImageNet EfficientNet-B4 with its configured frozen blocks.

M2

Focal classifier

Produces a binary real/manipulated logit and is trained with Focal loss.

M3

Dense mask head

Decodes a per-pixel forgery map supervised with Dice and BCE losses.

M4

Fixed-ROI localization

Reports review evidence for periocular, jawline, mouth, and hairline landmark boxes; it is not causal attribution.

Supervised learning signal

Classify the frame.
Localize review evidence.

The two heads are trained together against the frame label and available FF++ forgery mask. The fixed ROI boxes do not establish causal attribution.

Focal classification

Handles the binary real/manipulated frame label.

Dice mask loss

Encourages overlap between predicted and ground-truth forgery masks.

BCE mask loss

Provides per-pixel supervision for the dense forgery map.

Fixed sampling

Uniform frame selection keeps inputs deterministic and comparable.

Training approach

Train and evaluate in Docker.

Step 01

Prepare masks

FF++ supplies masks for its 5,200 fake records. Celeb-DF-v2 and DFDCP have no mask files in this extraction, so external evaluation is classification-only.

Step 02

Run supervised training

The deployed `--verdict honi05` path trains the heads over a frozen verdict backbone; the alternate path without `--verdict` uses the configured ImageNet EfficientNet-B4 freeze setting. Both use Focal, Dice, and BCE losses with fixed uniform sampling.

Runtime note

Use Docker Compose with the NVIDIA-enabled CUDA runtime on an RTX 4050. Evaluate only on documented video-disjoint splits, retain ambiguous clips as REVIEW, and do not claim broad production reliability without external validation.
